# CLAUDE.md

## Bilingual documents

These pairs are two versions of the same document, English and Korean:

- `scripts/README.md` / `scripts/README.ko.md`
- `AINL.md` / `AINL.ko.md`

Whenever one file of a pair changes, change the other in the same commit:

- Keep the same section numbering, heading order, script entries and code
  blocks. Translate prose and code comments; keep commands, paths and flags
  identical.
- Run `scripts/check-readme-sync.sh` (for the AINL pair:
  `scripts/check-readme-sync.sh AINL.md AINL.ko.md`) before committing. The
  `pre-commit` hook (`scripts/hooks/pre-commit`) checks both pairs too and
  blocks an out-of-sync commit.
- The "Changed files" list between the AUTO markers in both AINL files is
  generated by `scripts/update-ainl.sh`; do not edit it by hand.
